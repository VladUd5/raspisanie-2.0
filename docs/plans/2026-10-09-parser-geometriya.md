# План: разбор PDF по геометрии сетки

Спека: [2026-10-09-parser-geometriya-design.md](../specs/2026-10-09-parser-geometriya-design.md)

Ветки: `parser-geometriya` (стенд), `geometriya` (сабмодуль, локально, без push).
Корпус для разработки — 199 PDF последнего обхода (копия во временном каталоге).
Go — в контейнере `golang:1.25-bookworm`; Python — pdfplumber 0.11.10, как в образе парсера.

## Задачи

1. **Скрипт `scripts/pdf2cells.py`, видимая сетка.** Линии → атомарная сетка →
   видимые ячейки → текст. Тест: на М-ПИ-101 ячейка «лаб.з. Big Data … 520, 533»
   цельная.
2. **Столбцы, пары, недели, группы.** Тесты на М-ПИ-101 (имя, «русский язык» 15:20
   числитель, «Философские познания» 15:20 знаменатель, Big Data 17:00 обе недели)
   и «1 курс Б-ЛД-101» (группы Б-ЛА-101, Б-ЛД-101).
3. **Дни и даты.** Повёрнутый текст; тесты на заочный PDF с датой в ячейке дня и
   с отдельным столбцом «Дата».
4. **Прогон по корпусу.** Все 199 PDF без исключений; предупреждения разобраны.
5. **Go.** `ParsePDF` → новый скрипт, JSON → группы; `Day.Date`, `Group.Source`;
   удалить CSV-путь и его тесты; Dockerfile без pandas. `go test ./...`.
6. **Сверка `tools/parser_audit.py`.** Полнота слов, независимое время через
   `pdftotext -bbox`, разница со старым снапшотом; картинки спорных ячеек;
   ручной просмотр всех расхождений, итог — в журнал.
7. **Стенд: даты.** `flatten` (date, source), миграция `cells`, неделя сессии,
   дедупликация по свежему файлу, фильтр «Неделя сессии», дата в таблицах. Тесты.
8. **Пересбор.** Временный парсер из ветки → обход сайта → снапшот → загрузка в
   стенд; новые написания — ручная проверка, дописать словарь; тесты стенда.
9. **Документы.** README (ограничения 4–5, даты заочки), спека стенда, журнал.

Журнал решений и отклонений: `.superpowers/sdd/2026-10-09-parser-geometriya/progress.md`.
