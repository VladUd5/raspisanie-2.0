# Календарный учебный график: периоды, праздники, часы — план

**Цель:** из графиков учебного процесса брать не только сессии, а все периоды каждого курса
(теория, сессия, каникулы, практика); праздники — из производственного календаря; академические
часы считать только по дням теории; сбор расписания — дважды в неделю.

## Решения

- **Что показывается студентам.** Только подтверждённые учебным отделом периоды. Черновик
  распознавания ничего не скрывает и не пересчитывает: ошибка скана не должна прятать настоящие пары.
- **Праздники.** Нерабочие праздничные дни РФ (ст. 112 ТК: 1–6 и 8 января, 7 января, 23 февраля,
  8 марта, 1 и 9 мая, 12 июня, 4 ноября) плюс переносы. Переносы — дни, которые отмечены «=» в
  графиках вуза в нескольких файлах (знак мелкий, распознаётся не везде, поэтому голосование по всем
  файлам), и `HOLIDAYS_EXTRA` в `.env` для ручной правки (`WORKDAYS_EXTRA` — наоборот).
- **Семестр.** Порядок: дата в `.env` → по графикам (самая частая дата начала теории осенью и
  весной по всем файлам, нужно согласие хотя бы 5 файлов) → значения по умолчанию.
  `SPRING_START` больше не обязателен.
- **Периоды курса.** Подряд идущие дни одного вида: теория («пусто»), сессия («Э»), каникулы («К»),
  практика и прочее (У, П, Н, Д — «x»). Короткие (до 2 дней) куски «x» внутри теории — шум
  распознавания, остаются теорией. Неделя одной объединённой клеткой с буквой, кроме «Э»/«К», —
  практика (раньше считалась теорией).
- **Обновлённый график.** У файлов на сайте вуза есть ETag и Last-Modified. Раз в сутки — запрос
  HEAD по каждому известному файлу; изменился — распознать заново. Подтверждённые периоды не
  затираются: новый черновик ложится рядом, у файла пометка «график на сайте обновлён — сверьте».
  «Подтвердить черновик» заменяет подтверждённое по тем курсам, где есть черновик.

## Задачи

1. `kug.py`: объединённая клетка с прочей буквой → «xxxxxx»; `periods(marks, year)`;
   `save_drafts` хранит все виды (колонка `kind` в `sessions`, миграция 3); ETag в `kug_files`.
2. `academic.py`: праздники; периоды группы (подтверждённые); семестры по графикам.
3. `semester.py`: семестры — `.env` → графики → по умолчанию.
4. Часы (`public/stats.py`): только дни теории группы (если периоды подтверждены), без праздников.
5. Сетка недели и календарь `.ics`: праздник — пометка дня, пар нет; подтверждённые сессия,
   каникулы, практика — пометка недели, еженедельных пар нет.
6. Страница «Сессии»: колонка «Вид», подтверждение по курсам.
7. collector: сбор по дням недели (`COLLECT_DAYS`, по умолчанию пн и чт), ежедневные задачи
   (справочник, графики, копия) — отдельно от сбора; кнопка «Проверить сайт сейчас» на «Сводке».
8. Подписка на календарь: инструкция для Яндекса, кнопка для Google, проверка ленты разборщиком.
9. README, `.env.example`, памятка ИТ.
