# Словарь написаний

Проверенные вручную каноны написаний дисциплин, преподавателей, групп, мест и типов занятий.
Словарь применяется первым шагом нормализации; написания, которых в нём нет, обрабатываются
автоправилами и помечаются «не проверено» (страница «Словарь написаний»).

## Файлы

| Файл | Строк | Из них `l` | Канонов | Колонки |
|---|---|---|---|---|
| `disciplines.csv` | 2174 | 86 | 1002 | `написание, канон, уверенность, вид, примечание`; канон `—` — не дисциплина |
| `teachers.csv` | 688 | 44 | 476 | то же и `дисциплина` — строка действует только для этой дисциплины (однофамильцы) |
| `places.csv` | 4 | 3 | 4 | `корпус, как записано, корпус_канон, аудитория_канон, …` — только то, что разбор не исправит сам |
| `groups.csv` | 266 | 1 | 266 | `написание, канон, уверенность, вид, примечание` |
| `lesson_types.csv` | 27 | 0 | 4 | то же |

Уверенность: `h` — решение однозначно по данным, `l` — вероятно, подтверждается только по PDF или
кафедрой. Каждое написание проверялось в контексте: у дисциплины — преподаватели, группы и
институты, у преподавателя — дисциплины и институты, при сомнении — исходный текст ячейки.

Поле `вид` заполняется, только если автоматическая классификация ошибки неверна (например, `лб.з.` —
сокращение). Пустое имя группы в словарь не входит.

## Пополнение

1. На странице «Словарь написаний» выбрать «Источник канона: правило, как есть».
2. Для каждого написания определить канон и добавить строку в CSV (UTF-8, запятая, по алфавиту).
3. Проверить: `.venv/bin/python -m pytest tests/test_dictionary.py`.
4. Пересобрать: `docker compose up -d --build`. При изменении словаря снапшоты перечитываются
   автоматически.

Если файл не читается, остаются прежние данные, а в версии для руководства выводится
предупреждение с именем файла и номером строки.
